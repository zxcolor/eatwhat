# 合规、安全与公开发布门禁

本清单是工程门禁，不构成法律意见。公司应在公开发布前由中国境内合规顾问、云接入商和各数据供应商按实际业务复核。

## 数据与供应商

- [ ] 高德书面确认实时重排、自有适合度、POI ID 保存、候选交给第三方模型和商业授权边界。
- [ ] `LICENSED_ENRICHMENT` 的授权记录 ID、授权范围、负责人和到期时间可追溯；到期告警及自动/人工回退演练通过。服务端环境校验不能替代本项。
- [ ] 未获许可时保持 `LIVE_DISPLAY_ONLY`，不缓存、抓取、转送或伪装数据来源。
- [ ] 美团、大众点评、小红书、抖音等只通过正式开放平台或商务授权接入；本仓库不实现未经授权抓取。
- [ ] 千问工作空间、调用地域和日志策略确认位于境内；输入字段经隐私复核。
- [ ] 短信、微信、QQ、EMAS、天气等服务完成合同、SDK 字段和隐私政策登记。
- [ ] 所有第三方 SDK 在用户同意后初始化，且可由远程开关停用。

## App 与算法

- [ ] 单独完成 App 备案；已备案网站不能替代 App 备案。
- [ ] 公司主体、域名、服务器、包名、签名和备案信息一致。
- [ ] “吃什么”商标、应用商店重名和近似名称完成检索与法律判断。
- [ ] 用户协议、隐私政策、第三方 SDK 清单、数据来源、推荐规则和 AI 标识页面上线。
- [ ] 精确位置完成单独同意和个人信息保护影响评估；拒绝后手动选址可完整使用。
- [ ] 算法推荐自评、公开说明、投诉渠道和应急处置完成。
- [ ] 是否需要算法备案、等保定级或其他许可有书面结论。
- [ ] AI 生成/辅助内容按当时有效规则显著标识。
- [ ] 不以 14 岁以下儿童为目标；进入中小学场景前重新做未成年人方案。

## 账号与个人权利

- [ ] 手机号 + 微信双验证注册流程、风险验证和账号冲突专项测试通过。
- [ ] QQ/邮箱只能绑定现有账号；解绑不会造成账号接管。Android 1.0 不开放账号恢复，后续如立项必须重新完成防接管评审与验收。
- [ ] App 内可导出、清除偏好和注销；注销立即使所有令牌失效。
- [ ] 注销数据在 30 天内退出滚动备份；导出个人内容 7 天内由 worker 替换为经验证的永久 tombstone，OSS 生命周期不会删除 tombstone。
- [ ] 游客数据合并前明确询问，不静默上传。
- [ ] 个性化可关闭、查看、修改和清空，不暗中推断身份、收入或健康状态。

## 安全与运维

- [ ] 全链路 HTTPS；Access Token 短时、Refresh Token 轮换和重放检测。
- [ ] 管理台 MFA、最小权限 RBAC、风险告警和不可修改审计日志上线。
- [ ] 在上述管理台控制完成前，部署清单和云防火墙均证明管理台仅监听回环或受控内网，未通过反向代理、公网负载均衡或隧道旁路暴露。
- [ ] RAM 最小权限、密钥托管、加密数据盘和 OSS 私有桶完成复核。
- [ ] 网关/APM/SLS/应用日志均验证不会记录坐标、Token、手机号和第三方标识。
- [ ] 生产 `TRUSTED_PROXY_CIDRS` 与实际 SLB/Ingress 拓扑一致，伪造转发头、共享限流桶和多实例绕限流专项测试通过。
- [ ] 依赖漏洞、密钥泄露、静态代码、恶意 APK 和 SBOM 检查通过。
- [ ] 备份恢复演练成功；内测 RPO 24 小时/RTO 8 小时。
- [ ] Release 签名离线备份、APK 哈希和回滚手册完成。

## Go / No-Go

只有以上适用项全部关闭，并同时满足以下条件，才能公开提供 APK 或提交应用商店：

- 无 P0/P1 隐私、安全、数据授权、账号或主流程问题。
- 崩溃无故障会话率达到 99.5%，恢复演练成功。
- 50–100 人 Beta 的推荐、预算、重复和成本指标达到目标。
- 月度容量与成本测算通过；`DEMO` 数据和调试入口从生产构建禁用。
- 生产配置使用 `NODE_ENV=production` 和 `ALLOW_DEMO_DATA=false`，启动及无合法供应商时的安全失败路径已在预发布环境实测。
- 发布负责人签署版本化 Go/No-Go 记录。
