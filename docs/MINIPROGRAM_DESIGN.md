# 微信小程序：Android 视觉延伸说明

记录日期：2026-09-17。范围：`apps/miniprogram` 的共享外观与首页实现。

## Overview

本次依据现有 Android 单人用餐流程构建微信小程序，交付目标为无真实 AppID 也可导入的工程。此文件记录已构建的跨平台延伸，不定义新的全仓设计系统，也不替代 Android 的实现与设计依据。源码是颜色和尺寸的准确信息源；后续代码变更时同步更新本说明。

### Direction contract

- **THESIS / Operate：** 让用户从推荐起点和本次条件走到“帮我决定”，以清晰的操作顺序承接 Android 的单人决策体验。
- **OWN-WORLD：** 浅灰蓝页面、白色卡片、蓝色主动作、深蓝横幅和圆角控件；深色主题保留同一结构与语义。使用文字和已有原生控件，不新增插画或生成图。
- **STORY：** 品牌 → 蓝色横幅 → 地点 → 极速/精细 → 主动场景 → 条件。用户先理解用途，主动选择推荐起点，再决定使用默认条件或细调。
- **FIRST VIEWPORT：** 顶部左侧品牌、右侧设置；横幅下面是地点与定位说明，再进入两列模式选择。底部固定“帮我决定”和候选数量说明，页面其余部分纵向滚动；首屏实际露出范围随设备变化。
- **FORM：** 既有 Android 视觉和操作结构的微信小程序延伸，不进行新视觉世界的候选选择。手动地点初始折叠；没有多人用餐、直接餐厅关键词搜索或餐厅分享入口。
- **FINISH：** “unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance”。本次普通延伸的文档落点为本文件；独立修复复核的 `ship` 仅适用于下述 F1/F2，不扩展为微信原生验收通过。

### 参考与实际延伸

Android 参考为 [首页浅色截图](./screenshots/single-user-quality-20260912/home-light.png)。当前小程序保留品牌、横幅、地点卡、两种决定模式、主动场景以及底部主动作的顺序和语义。横幅采用纯色；设置、定位和模式入口使用文字按钮，没有复刻 Android 截图中的碗插画、图标或渐变。这是当前已构建的差异，不宣称像素一致。

## Typography

共享字体栈为 `-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`。没有嵌入字体；中文最终字形与字重由微信所在设备决定。

| 使用位置 | 当前源码值 | 范围与解释 |
| --- | --- | --- |
| 共享正文 | `28rpx`，行高 `1.55` | 其他页面继续采用各自 WXSS 覆盖 |
| 首页正文、按钮、表单标签、小标题、搜索输入 | `14px` | 首页样式末尾的明确覆盖，避免随窄屏继续缩小 |
| 首页推荐按钮 | `16px`，继承字重 `600` | `.page .recommend` 的最终字号 |
| 首页副标题、提示、定位说明、模式说明、极速摘要、结果说明、页脚说明 | `12px` | 仅对末尾列出的选择器生效 |
| 品牌标题 | `46rpx`，字重 `750`，行高 `1.3` | 仍随视口缩放 |
| 横幅标题 | `52rpx`，字重 `750`，行高 `1.35` | 显式换行，仍随视口缩放 |
| 地点名称 | `33rpx`，字重 `700`，行高 `1.4` | 地点作为操作上下文优先可见 |
| 分区标题 | `32rpx`，字重 `700` | 首页“怎么决定”等标题 |
| 状态徽标 | `23rpx` | 未包含在首页固定字号覆盖中 |

`rpx` 与固定 `px` 在此并存，不能将首页修复表述为全小程序所有文字都有统一最小字号。以 375px 视口计算，`28rpx` 为 14px；更窄视口下仍使用 `rpx` 的标题、间距和徽标会继续缩放。

## Layout

页面为单列操作流。共享外边距由 `padding: 32rpx 28rpx` 提供；首页地点按钮和模式选项为两列等宽布局，间距 `16rpx`。条件标签可换行，间距 `12rpx`。卡片内边距 `28rpx`、上下外边距 `24rpx`；横幅内边距为 `38rpx`。

首页底部操作区固定于视口底边，使用 `22rpx 28rpx` 的上/侧内边距，下内边距为 `20rpx + env(safe-area-inset-bottom)`，层级为 `z-index: 5`。首页内容预留 `244rpx + env(safe-area-inset-bottom)` 的下方空间。这些是实现值；安全区是否正确响应、软键盘是否遮挡输入及底部按钮，仍需微信原生运行时验证。

手动地点选择区初始关闭，点击“手动选择”展开；选中搜索结果或快捷地点后收起。极速模式展示条件摘要，精细模式展示输入与可用筛选项；专项能力按服务端声明呈现。地点搜索只选择学校、商圈或地址等推荐起点，不是直接餐厅关键词搜索。

## Elevation & Depth

当前共享样式和首页主要使用表面色、间距和边界表达层次，没有悬浮阴影体系。标签选中态的 `inset 0 0 0 2rpx` 是内部描边效果；模式选中态同时改变背景、文字和边框颜色。全局底部弹层使用 `rgba(9, 18, 35, .56)` 遮罩、`z-index: 20` 和最多 `80vh` 的可滚动内容区。

## Shapes

卡片圆角为 `28rpx`，横幅为 `30rpx`，共享按钮为 `24rpx`，首页筛选标签为 `20rpx`，输入框和定位说明为 `18rpx`。状态徽标采用 `999rpx` 胶囊圆角；弹层顶部两个角为 `30rpx`。这些值来源于当前组件，不推广成跨平台通用半径刻度。

## Components

| 组件 | 实际样式与状态 |
| --- | --- |
| 主/次/描边按钮 | 共享内边距 `22rpx 24rpx`，共享最小高度 `88rpx`；首页末尾 `.page button` 将最小高度覆盖为 `44px`，也覆盖推荐按钮原先的 `98rpx`。主按钮使用主动作色，次按钮使用轻强调色，手动选择使用 `1rpx` 边框。 |
| 按钮反馈 | 共享按下态透明度 `.78`；禁用态用次级表面与辅助文字，透明度 `.65`。加载使用原生 `loading` 属性，推荐服务未就绪或正在推荐时不能提交。 |
| 地点卡 | 名称、已选择/待选择徽标、主动定位说明和两项地点操作组成一个整体。界面写明“定位只会在你主动点击后开始；位置只用于本次推荐。” |
| 决定模式 | 两列、内边距 `26rpx 20rpx`、`2rpx` 边框，当前模式用主色边框和轻强调背景；标题下有“少操作”或“更可控”的说明。 |
| 条件标签 | 内边距 `20rpx 22rpx`，首页最终最小高度 `44px`、字号 `14px`；选中通过底色、文字及内部描边共同表达。排除菜系使用错误语义色。 |
| 输入框 | 共享最小高度 `88rpx`、内边距 `18rpx 20rpx`、`1rpx` 边框。首页搜索输入为 `14px`，其他输入仍以共享样式和页面实际覆盖为准；按钮的 `44px` 规则不会自动覆盖输入框。 |
| 固定推荐操作 | 文案“帮我决定”，加载时“正在帮你筛选”；下方提示“最多 3 个候选 · 每个选择都有可核对理由”。 |
| 导航与主题 | 应用配置有 10 条页面路由，无底部标签栏。内容根节点应用主题类，`theme.ts` 同步导航栏文字/背景和页面背景；原生标题为“吃什么”。 |

外观偏好为 `SYSTEM`、`LIGHT`、`DARK`，缺省为 `SYSTEM`。页面显示时读取本机偏好并监听系统主题变化，隐藏和卸载时移除监听；未能获取系统主题时采用浅色。主题更新不依赖网络请求。应用配置声明 `darkmode: true`，导航栏浅色使用黑字、深色使用白字。

## Do's and Don'ts

- **Do：** 延续 Android 的单人决策顺序，保留主动定位说明、默认折叠的手动地点区和固定主动作。
- **Do：** 后续页面优先使用已有颜色变量与共享组件；记录页面级覆盖的实际生效范围。
- **Do：** 将源代码事实、浏览器布局预览、微信开发者工具和真机结果分别标注。
- **Don't：** 以视觉同步为由新增多人、直接餐厅关键词搜索、餐厅分享或后台定位入口。
- **Don't：** 将 F1/F2 修复的 `ship` 写成全界面或微信原生验收通过。
- **Don't：** 为本次普通延伸创建全仓 `PRODUCT.md`、`DESIGN.md` 或 `.impeccable/design.json`，或改写 Android 的既有视觉系统。
