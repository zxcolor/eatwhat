# Android 食物主题首页

本次把已确认的首页效果图落到原生 Compose：暖白背景、轻微暖色光晕、三餐分段选择，以及中央“现在决定”按钮。早餐使用面包，午餐使用蛋包饭，晚餐使用煎饺。文字使用原生半粗无衬线字体：面包为白字，浅色食物为深棕字。

首页不再展示品牌顶部栏、宣传标题、说明小字和长条件表单。底部位置胶囊打开定位面板，手动选址在面板内；旁边的条件按钮打开现有条件表单，并提供“设置与账号”入口。普通情况下的中央按钮最大宽度为 252 dp；点击有轻微弹性缩放，餐段切换有 220 ms 淡入淡出。

## 功能与边界

- 三餐始终保留在首页；服务尚未开放的餐段禁用，并提供无障碍状态说明。继续使用原有能力声明和 ViewModel 校验。
- 点击“现在决定”继续调用原有推荐流程；缺少地点时打开定位面板。配置异常、输入错误和距离纠正继续明确显示。
- 自动定位、权限拒绝、大致定位、提高精度、手动选址、预算、时间、交通、距离、菜系以及服务支持的专项条件继续使用现有逻辑。
- 小屏、横屏或大字体采用可滚动布局。底部控件有触控与无障碍描述；长地点名称省略显示，原始地点保留在选择面板。
- 修改只作用于首页及对应测试导航。结果页、账号流程、推荐算法、接口契约和服务端配置保持原状。
- Debug 与 Alpha 仍使用受控公网 HTTPS API；设备内合成测试使用独立 Fixture APK。固定 Alpha 包名、签名和公开 AppID 沿用既有受控配置。

## 美术资源

`drawable-nodpi/home_food_bread.png`、`home_food_omelette.png`、`home_food_dumpling.png` 为本次使用 ImageGen 生成的食物按钮素材，不来源于餐厅、菜单或供应商图片，不表示真实餐厅或商品。原始图采用 1774×887 画布，使用原生轮廓裁剪消除底色，文字、阴影、光晕和交互由 Compose 绘制。

生成方向：暖色精细食物材质，正面略俯视，横向居中，素色背景，无文字、盘子和其他装饰。面包背景在生成工具中单独清理，保留原有构图。素材只在本地打包，没有新增图片请求或缓存第三方内容。
