# eatwhat.pro 路演预告页

独立静态首页，入口为 `index.html`，无需构建或运行时依赖。将本目录作为静态 HTTP 服务根目录即可预览，也可直接打开 HTML。只展示用户指定的预告文案，不请求 API、不收集数据。

视觉为深空背景、粒子轨道、金属渐变中文字和扫光。右上角可暂停装饰动画；遵循系统 `prefers-reduced-motion`，页面隐藏时暂停 Canvas；手机和窄屏使用单独排版。字体本地打包，来源与 OFL 许可见 `assets/fonts/`。

## 验证

- `node --check apps/landing/scene.js`
- `git diff --check`
- 浏览器检查桌面、768px、390px、320px 视口：文案、资源加载、无横向溢出、暂停/恢复、减少动态效果。
- 合并仍按根目录 AGENTS.md 执行完整验证与当前提交的 GitHub CI。

## 发布边界

仅替换主站 `index.html`，样式、脚本与字体放入以内容哈希区分的独立资源目录，避免长缓存冲突。候选版本从当前主站完整复制后组装，保留原有隐私、协议、支持页面和它们的资源。切换前备份当前版本，验证后原子切换主站 `current` 软链接；回滚指回切换前的版本。

不修改 Nginx、API、数据库、Android 或微信小程序。源文件中的相对资源路径在部署包中统一加上该版本的资源目录前缀。公网 HTML、CSS、JS、字体响应及原有子页面必须独立核验。
