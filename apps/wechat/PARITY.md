# 安卓功能对照

基线：`2534e6ccdff717c8524b10785dee378e0d63f03c`，Android `0.1.10-alpha` / versionCode 11。新小程序自身版本 `0.1.11-alpha`。

| 功能 | 当前小程序实现 | 剩余验收或工作 |
| --- | --- | --- |
| 首页与底栏 | 极简标题、城市入口、骰子决策卡；首页 / 历史 / 个人固定胶囊底栏 | 真机尺寸与深色外观 |
| 隐私与服务配置 | 同意前零应用网络；撤回取消在途、清位置/结果；版本与能力失败关闭 | 微信后台隐私声明、真机权限 |
| 地点 | 主动 WGS84 定位；自有 API 关键词选址；城市单独解析 | 定位与关键词真实联网；公共地标快捷回退未移植 |
| 条件 | 预算、时间、交通、半径、排除菜系；能力控制专项和偏好 | 安卓快捷场景与完整偏好配置仍需补齐 |
| 推荐 | 最多三项、来源顺序、原因、空态/错误/重试、结果有效期 | 真实餐厅请求、结果本地筛选、行为事件 |
| 详情 | 数据来源/价格/距离/营业状态；按 actions 控制地图/拨号/复制 | 真机动作；禁止分享；账号收藏/反馈未接入 |
| 历史 | 当前 LIVE 模式关闭态 | 收藏、历史、私有反馈分页与管理未移植 |
| 账号 | 微信 code2Session 独立通道；手机号注册/登录、邮箱登录、身份/跨端设备读取、退出 | 云端通道启用和同一账号真实双端验证；绑定/解绑、设备撤销、导出、注销待接入 |
| QQ | 小程序无 QQ 登录入口；已有 QQ 身份可只读显示 | 安卓 QQ 登录保持原样 |
| 设置 | 明/暗/跟随系统、版本、服务重查、隐私撤回 | 安卓本机决策、附近缓存管理、问题反馈等未移植 |
| 附近餐厅收集 | 未实现本地后台收集或缓存 | 必须单独移植并验证授权、90天保留、清理和迟到响应规则 |

所有客户端单元测试使用合成数据；通过测试不代表真实微信身份、供应商或生产数据库验收。生产 API 本轮仅验证 `/health/ready` 和 `/v1/config` 读取成功。
