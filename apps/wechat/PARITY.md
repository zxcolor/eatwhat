# 安卓功能对照

账号功能复刻基线：`2534e6ccdff717c8524b10785dee378e0d63f03c`，Android `0.1.10-alpha` / versionCode 11。小程序本地候选版本 `0.1.18-alpha`。本次决定流程按用户要求采用首启偏好选择、虚拟数据与单结果研究算法，已不与 Android 实时推荐流程逐项一致；Android 本身未修改。

| 功能 | 当前小程序实现 | 剩余验收或工作 |
| --- | --- | --- |
| 首启偏好 | 首先收集类型、避开项、预算、辣度与取舍；每次回答更新就绪判定，完整答案须在套餐和餐厅可行池中形成精确效用差异，或由明确硬条件筛出唯一选择；不足时停留问题页 | 390 项小程序测试与开发者工具隔离模拟器流程通过；真机待验收，规则就绪不代表真实满意度认证 |
| 偏好保存与编辑 | 用户主动开始后仅保存在本机；确认偏好 90 天、未完成草稿 7 天；编辑立即关闭决策，重新确认才恢复；支持清除与撤回 | 实际设备存储异常、到期与恢复验收；不上传、不训练个人模型 |
| 首页与底栏 | 北京时间标题、虚拟地图入口、有边界的决策按钮；首页 / 历史 / 个人固定胶囊底栏；推荐在首页底部面板展开 | 真机尺寸、滚动、深色外观与触摸反馈 |
| 隐私与服务配置 | 同意前零应用网络；撤回取消在途、清位置/结果；版本与能力失败关闭 | 微信后台隐私声明、真机权限 |
| 地点 | 0–1000 虚拟地图坐标；距离只用虚拟单位，不调用 GPS 或地点 API | 开发者工具与真机控件验收 |
| 条件 | 套餐/餐厅目标，虚拟预算/距离/辣度/素食硬条件，以及价格/距离/模拟正餐偏好 | 开发者工具与真机控件验收 |
| 推荐 | 有效且已确认的偏好为入口条件；12 类餐厅类型偏好参与精确效用，避开类型是硬排除；完整虚拟目录直接选一项，不重复换一个，保留主动随机/加权抽取；空态区分未知与不可行 | 开发者工具实际结果已检查，真机待验收；类型是店铺分类，不能证明菜品、配料或过敏原 |
| 详情 | 当前单卡事实、来源边界、决定依据和未知项；确认只记本次内存中的虚拟选择 | 不导航/拨号/上传推荐反馈，不产生订单 |
| 账号记录 | 想去/常吃双收藏分组、移动/删除；历史与私有反馈分页/清空，安全详情 | LIVE 模式关闭；真实授权数据下验收 |
| 账号 | 微信 code2Session；手机号注册/登录、邮箱登录/绑定/解绑、已有微信解绑、跨端设备撤销、退出、注销 | 云端通道启用与同一账号真实双端验证；小程序首次绑定微信尚未移植，QQ只读 |
| 数据导出 | 范围选择、申请/状态、完整性/UTF-8/契约/账号校验、内存分页阅读 | 尚不导出本地文件；wx.request 无已验证的禁止重定向开关，保留域名与响应门控并待真机验证 |
| QQ | 小程序无 QQ 登录入口；已有 QQ 身份可只读显示 | 安卓 QQ 登录保持原样 |
| 设置与反馈 | 偏好修改/清除、外观/版本/服务重查/隐私撤回；四类问题反馈、幂等重试与失效账号的游客确认 | 真实反馈工单验收 |
| 本机最近决策 | 保留旧七字段摘要的读取/清理；虚拟决定与确认不写入这些记录 | 实际设备存储异常验收 |
| 附近餐厅缓存 | 保留独立授权页面与既有边界；虚拟首页不触发附近采集，最多两页50家、90天 | 实际定位与授权数据验收；退出期间不后台定位，过期数据在下次读取/启动清理 |

所有客户端单元测试使用合成数据；通过测试不代表真实微信身份、供应商或生产数据库验收。生产发布与数据库演练证据见 [PR #23](https://github.com/zxcolor/eatwhat/pull/23)；同一账号的真实双端登录仍需实际验收。
