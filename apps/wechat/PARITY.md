# 安卓功能对照

基线：`2534e6ccdff717c8524b10785dee378e0d63f03c`，Android `0.1.10-alpha` / versionCode 11。新小程序自身版本 `0.1.11-alpha`。

| 功能 | 当前小程序实现 | 剩余验收或工作 |
| --- | --- | --- |
| 首页与底栏 | 极简标题、城市入口、骰子决策卡；首页 / 历史 / 个人固定胶囊底栏 | 真机尺寸与深色外观 |
| 隐私与服务配置 | 同意前零应用网络；撤回取消在途、清位置/结果；版本与能力失败关闭 | 微信后台隐私声明、真机权限 |
| 地点 | 主动 WGS84 定位；自有 API 关键词选址；城市单独解析；安卓公共地标示例回退 | 定位与关键词真实联网、平台权限验收 |
| 条件 | 三个快捷场景；预算、时间、交通、半径、偏好/排除菜系、五项权重；能力控制专项/体感/AI | 真机控件和各服务能力组合验收 |
| 推荐 | 最多三项、来源顺序、原因、空态/错误/重试、有效期；营业/已知价格/菜系本地筛选；匿名短期标识事件 | 真实餐厅请求与行为事件验收 |
| 详情 | 按 actions 控制地图/拨号/复制；授权模式下收藏、八种私有反馈 | 真机动作；分享保持关闭 |
| 账号记录 | 想去/常吃双收藏分组、移动/删除；历史与私有反馈分页/清空，安全详情 | LIVE 模式关闭；真实授权数据下验收 |
| 账号 | 微信 code2Session；手机号注册/登录、邮箱登录/绑定/解绑、已有微信解绑、跨端设备撤销、退出、注销 | 云端通道启用与同一账号真实双端验证；小程序首次绑定微信尚未移植，QQ只读 |
| 数据导出 | 范围选择、申请/状态、完整性/UTF-8/契约/账号校验、内存分页阅读 | 尚不导出本地文件；wx.request 无已验证的禁止重定向开关，保留域名与响应门控并待真机验证 |
| QQ | 小程序无 QQ 登录入口；已有 QQ 身份可只读显示 | 安卓 QQ 登录保持原样 |
| 设置与反馈 | 外观/版本/服务重查/隐私撤回；四类问题反馈、幂等重试与失效账号的游客确认 | 真实反馈工单验收 |
| 本机最近决策 | 七字段条件摘要，最多30条/90天；无餐厅、位置或账号信息；可清理 | 实际设备存储异常验收 |
| 附近餐厅缓存 | 独立授权默认关闭；每次前台一次、3.5km、最多两页50家、90天；容量与清理/迟到响应防护 | 实际定位与授权数据验收；退出期间不后台定位，过期数据在下次读取/启动清理 |

所有客户端单元测试使用合成数据；通过测试不代表真实微信身份、供应商或生产数据库验收。生产发布与数据库演练证据见 [PR #23](https://github.com/zxcolor/eatwhat/pull/23)；同一账号的真实双端登录仍需实际验收。
